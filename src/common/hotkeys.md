# Hotkeys / Keybinds / Keyboard shortcuts

Throughout the platform we have included some hotkeys to help you navigate and work faster.

> You can access and visualise these shortcuts by typing '?' outside of an input field.

Hotkeys are divided into page hotkeys, and global hotkeys.

The page hotkeys as you might expect, pertain to actions which are only available on the current page you are viewing, these actions may appear or disappear depending on conditions on the page (as an example, a Save hotkey might only be visible if you have made changes on the page).

Global hotkeys are available at any time, and can help you to access powerful features like the documentation and platform search, or to quickly relocate to a different area of the platform.

## Common Hotkeys

Whilst not all hotkeys are available on all pages (we encourage you to use the hotkey visualizer to get a feel for what is available),
here is a selection of some of our available hotkeys.

| Function | Shortcut | Description |
|----------|---------|-------------|
| **Core / Most Frequent Actions** |||
| New | Alt+N | Create a new item |
| Save | Ctrl+S, Cmd+S | Save current changes |
| Copy | Ctrl+C, Cmd+C | Copy selection |
| Paste | Ctrl+V, Cmd+V | Paste from clipboard |
| Undo | Ctrl+Z, Cmd+Z | Undo last action |
| Redo | Ctrl+Y, Cmd+Y, Ctrl+Shift+Z, Cmd+Shift+Z | Redo last undone action |
| Select | Enter | Select current item |
| Open | Alt+O | Open an item |
| **Workflow / Execution** |||
| Run | Alt+R | Execute/run item |
| Run Special | Shift+R | Execute with special options |
| Publish | Alt+P | Publish an item |
| **Navigation** |||
| Open More Menu | Alt+M | Open the tab level 'more' menu |
| Open Inner More Menu | Alt+Shift+M | Open the inner 'more' menu |
| **Deletion / Cleanup** |||
| Close | Esc | Close current view |
| Clear | Ctrl+Backspace | Clear content |
| Delete | Cmd+Backspace, Delete | Delete item |
| **Search** |||
| Search | K | Quick search |
| Query | Alt+Shift+Q | Open query interface |
| Global Search | Ctrl+K, Cmd+K | Search your workspace|
| Doc Search | Ctrl+Shift+K, Cmd+Shift+K | Search documentation |
| Find | Ctrl+F, Cmd+F | Find in current view |
| **UI** |||
| Fullscreen | Cmd+Enter, Alt+Enter | Toggle fullscreen mode |
| Zoom In | Ctrl+=, Cmd+= | Increase zoom level |
| Zoom Out | Ctrl+-, Cmd+- | Decrease zoom level |
| Zoom Reset | Ctrl+0, Cmd+0 | Reset zoom to default |
| Left Pane | Alt+Q | Toggle/Cycle left pane |
| **Globals** |||
| Go To Home | Ctrl+Alt+H | Navigate to home |
| Toggle Main Nav | ], Alt+` | Toggle main navigation |
| Toggle Theme | Ctrl+Alt+L | Switch between themes |
