# Platform SSO Providers

This page allows you to set up Single-Sign-On on your Toca platform by linking to an :docs-link[Identity Provider]{id="admin/identity_providers"}

If the Identity provider has been configured correctly, you should be able to simply add a new SSO Provider via the add icon at the top right of the screen, then set a name for it.

A new button will appear on your platform's login page, with the icon and name you select, and allow users to log in using that platform.

If you have 'Require approval' enabled (we recommend that you do), an admin will have to manually approve each user which logs in with SSO before they will have full access to the platform, this is done via the 'User Approval' admin page, accessible via the admin navigation menu.
