# Workspaces
Workspaces are a wrapper for all related automation and apps. 

## Workspace name (required)
Give your workspace a name that identifies its purpose.

## Workspace route (required)
This will form part of the URL and allows you to link directly to this workspace. The route is limited to characters safe to use in a URL: letters, numbers, underscores and hyphens.

## Description (required)
A longer description of what the purpose of this workspace is. It will appear in lists of workspaces.

## Workspace colour (required)
An accent colour to make the workspace easier to identify.

## Workspace icon (optional)
Either an image for icon to use as an avatar for the workspace.

## Enable CMS (if enabled)
Enable CMS in the workspace. If enabled CMS will appear as an option in the main navigation and in app dependencies.

## Version control
Version control allows you to control what automation and apps are live, and which are in development.

If enabled it will use Git branches.
